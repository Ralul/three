How it works

Three.js is the foundation of the 3D environment in this project.
It provides a high‑level interface to the WebGL API, making it possible to create, light, and animate fully interactive 3D scenes directly in the browser without external plugins.
In the chess game, Three.js handles everything from modeling the pieces and rendering the board to setting up the virtual camera, lighting, and shadows.
Thanks to its object‑oriented scene structure, I can efficiently manage materials, textures, and mesh hierarchies—allowing realistic graphics while maintaining smooth frame rates even on lightweight devices.

TypeScript forms the backbone of the game’s logic and architecture.
It extends JavaScript with static typing, which helps catch errors early and makes complex systems—like move validation, AI decision trees, and real‑time game state tracking—more predictable and robust.
The strong type system also ensures clean modularity: each component (board, piece, player, and renderer) is easier to test and maintain.
TypeScript’s modern tooling and integration with editors like VS Code make the development experience smoother and the codebase more scalable for future features such as multiplayer or visual themes.
